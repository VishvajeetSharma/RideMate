# 🚗 RideMate – Ride Booking System

A real-time ride booking platform built with the **MERN Stack**, **Socket.IO**, and **Leaflet**.

### 🚀 Tech Stack

- React.js
- Node.js
- Express.js
- MongoDB
- Socket.IO
- Leaflet

### ✨ Features

- User & captain authentication
- Ride booking
- Real-time ride requests
- Captain assignment
- Real-time location tracking
- Interactive maps with Leaflet
- Real-time ride status updates
- Admin dashboard
- Ride management
